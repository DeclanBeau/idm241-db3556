Shuffle Button

Located on the left side of the playback bar at the bottom of the screen while a song is playing.

Enable Shuffle

TRIGGERS:

  • Hover On
  • Hover Off
  • Click On
  • Click Off

RULES

Hover On

  • Cursor changes to finger
  • Label saying "Enable Shuffle" fades in above button
  • Button fades from white to green
  • Button grows by .1 rem

Hover Off

  • Cursor changes to pointer
  • Label fades out
  • Button fades back to white
  • Button shrinks back to default

Click On

  • Label changes from "Enable Shuffle" to "Disable Shuffle"
  • Dot fades in the top right shuffle button
  • Database is updated to shuffle user's queue

Click Off

  • Label fades out
  • Dot fades out
  • Database is updated to unshuffle user's queue

FEEDBACK

Hover On

  • Cursor changes to finger
  • Label saying "Enable Shuffle" fades in above button
  • Button fades from white to green
  • Button grows by .1 rem

Hover Off

  • Cursor changes to pointer
  • Label fades out
  • Button fades back to white
  • Button shrinks back to default

Click On

  • Label changes from "Enable Shuffle" to "Disable Shuffle"
  • Dot fades in at the top right shuffle button

Click off

  • Label fades out
  • Dot fades out

LOOPS/MODES

  • None

Repeat Button

Located on the right side of the playback bar at the bottom of the screen while a song is playing.

Enable Repeat

TRIGGERS:

  • Hover On
  • Hover Off
  • Click On
  • Second Click On
  • Click Off

RULES

Hover On

  • Cursor changes to finger
  • Button Spins 360 degrees
  • Button fades from white to green
  • Label saying "Enable Repeat" fades in above button

Hover Off

  • Cursor changes to pointer
  • Button fades back to white
  • Label fades out

Click On

  • Label changes from "Enable Repeat" to "Enable Repeat One"
  • Dot fades in on top right of reapeat button
  • Database is updated to reapeat user's queue

Second Click On

  • Label changes from "Enable Repeat One" to "Disable Repeat"
  • Number 1 fades in on top right of repeat button
  • Database is updated to reapeat user's current song

Click off

  • Button fades from geen to white
  • Label fades out
  • Dot fades out
  • Database is updated to not repeat user's song

  • Label saying "Enable Repeat" fades in above button

Hover Off

  • Label fades out

Click On

  • Dot fades in on top right of reapeat button

Second Click On

  • Number 1 fades in on top right of repeat button

Click off

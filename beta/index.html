Shuffle Button

Located on the left side of the playback bar at the bottom of the screen while a song is playing.

TRIGGERS:

  • Hover On
  • Hover Off
  • Click On
  • Click Off

RULES

Hover On

  • Cursor changes to finger
  • Label saying "Enable Shuffle appears above button
  • Button turns from white to green
  • Button grows by .1 rem

Hover Off

  • Cursor changes to pointer
  • Label dissapears
  • Button goes back to white
  • Button shrinks back to default

Click On

  • Label changes from "Enable Shuffle" to "Disable Shuffle"
  • Dot appears at the top right shuffle button
  • Database is updated to shuffle user's queue

Click off

  • Label Dissapears
  • Dot dissapears
  • Database is updated to unshuffle user's queue

Repeat Button

Located on the right side of the playback bar at the bottom of the screen while a song is playing.

TRIGGERS:

  • Hover On
  • Hover Off
  • Click On
  • Second Click On
  • Click Off

RULES

Hover On

  • Cursor changes to finger
  • Button Spins 360 degrees
  • Button turns from white to green
  • Label saying "Enable Repeat" appears above button

Hover Off

  • Cursor changes to pointer
  • Button goes back to white
  • Label dissapears

Click On

  • Label changes from "Enable Repeat" to "Enable Repeat One"
  • Dot appears on top right of reapeat button
  • Database is updated to reapeat user's queue

Second Click On

  • Label changes from "Enable Repeat One" to "Disable Repeat"
  • Number 1 appears on top right of repeat button
  • Database is updated to reapeat user's current song

Click off

  • Button changes from geen to white
  • Label Dissapears
  • Dot dissapears
  • Database is updated to not repeat user's song

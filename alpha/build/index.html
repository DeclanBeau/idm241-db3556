Shuffle Button

Located in the playback bar at the bottom of the screen while a song is playing.

TRIGGERS:

  • Hover On
  • Hover Off
  • Click On
  • Click Off

RULES

Hover On

  • Cursor changes to finger
  • Label saying "Enable Shuffle for [Song]" appears above button
  • Button turns from 75% opacity to 100% opacity
  • Button grows by .1 rem

Hover Off

  • Cursor changes to pointer
  • Label dissapears
  • Button goes back to 75% opacity
  • Button shrinks back to default

Click On

  • Button changes from white to green
  • Label changes from "Enable Shuffle" to "Disable Shuffle"
  • Dot appears under shuffle button
  • Database is updated to shuffle user's queue

Click off

  • Button changes from geen to white
  • Label Dissapears
  • Dot dissapears
  • Database is updated to unshuffle user's queue

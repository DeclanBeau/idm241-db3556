Shuffle Button

Located on the left side of the playback bar at the bottom of the screen while a song is playing.

TRIGGERS:

  • Hover On
    • Default
    • Active
  • Hover Off
    • Default
    • Active
  • Click On
  • Click Off

RULES

Hover On

Default
  • Cursor changes to finger
  • Label saying "Enable Shuffle" fades in above button
  • Button changes from white to green based on location of user's mouse
  • Button grows by .1 rem
Active
  • Cursor changes to finger
  • Label saying "Disable Shuffle" fades in above button

Hover Off

Default
  • Cursor changes to pointer
  • Label fades out
  • Button changes back to white based on location of user's mouse
  • Button shrinks back to default
Active
  • Cursor changes back to pointer
  • Label fades out

Click On

  • Label changes from "Enable Shuffle" to "Disable Shuffle"
  • Dot fades in the top right shuffle button
  • Database is updated to shuffle user's queue

Click Off

  • Label fades out
  • Dot fades out
  • Database is updated to unshuffle user's queue

Skip Button

First button on the right side of the playback bar at the bottom of the screen while a song is playing.

TRIGGERS:

  • Hover On
  • Hover Off
  • Click On

RULES

Hover On

  • Cursor changes to finger
  • Button changes from white to green based on location of user's mouse

Hover Off

  • Cursor changes to pointer
  • Button changes back to white based on location of user's mouse

Click On

  • Button animates moving to the right, off the screen
  • Button turns back to white, and animates back to original position from the left
  • Database is updated to change user's song to the next in queue

FEEDBACK

Hover On

  • Cursor changes to finger
  • Button changes from white to green based on location of user's mouse

Hover Off

  • Cursor changes to pointer
  • Button changes back to white based on location of user's mouse

Click On

  • Button animates moving to the right, off the screen
  • Button turns back to white, and animates back to original position from the left
